# Academic Laboratory Report Generators

This directory contains standalone utility scripts developed during the academic semester to programmatically compile, format, and audit Word (`.docx`) and presentation (`.pptx`) reports for Laboratories 2, 5, 6, and 7.

## Contents
- `generate_lab2_report.py`, `generate_lab2_final_report.py`: Scripts used to generate the Laboratory 2 report.
- `generate_lab5_report.py`: Script used to assemble the Laboratory 5 report with Room schema and SQLite analytics.
- `generate_labs_6_7_reports.py`, `generate_lab7_final.py`: Scripts used to assemble Laboratory 6 (ML) and Laboratory 7 (Integration) deliverables.
- `audit_final_docx.py`, `audit_omml_semantics.py`, `check_mathml_transform.py`, `insert_omml_equations.py`: XML and MathML/OMML formula validation utilities.
- `create_diagram.py`, `ble_state_machine.png`: Diagram rendering utilities for BLE state machine documentation.
- `inspect_docx.py`, `make_contact_sheets.py`, `render_logcat_image.py`: Visual QA and layout inspection helpers.
