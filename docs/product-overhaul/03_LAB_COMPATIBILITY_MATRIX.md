# Матриця сумісності лабораторних робіт (Labs 1–7 Compatibility Matrix)

**Принцип модернізації:** жодна з функцій лабораторних робіт 1–7 не повинна бути втрачена.  
Для користувача надається чистий продуктовий інтерфейс `SleepSense`, а всі технічні інспектори, емулятори та тестові сценарії концентруються у спеціальному розділі **Developer Lab**.

---
