# Профілювання Lab 7

Дата: 19.10.2026. Пристрій: Android Emulator `Pixel_10_Pro`. Збір виконано через `adb dumpsys meminfo`, `cpuinfo` та `gfxinfo` для debug APK.

|---|---:|---:|---:|
| після запуску | 115111 KB | 248764 KB | 0 KB |
| 30 с моніторингу | 130093 KB | 275868 KB | 0 KB |

| після 10 force-stop/start циклів | 92940 KB | 210920 KB | 0 KB |

За інтервал 30–60 с PSS зменшився на 716 KB. Після десяти повних перезапусків PSS не накопичувався. Це не доводить відсутність витоків, але не показує монотонного росту у виконаному сценарії.

`gfxinfo` зафіксував 1028 кадрів, 946 janky frames за сучасною метрикою, медіану 20 ms, p90 65 ms, p95 101 ms, p99 250 ms. Результат незадовільний для production UX і відображає debug-збірку в навантаженому AVD. Профілювання фізичного пристрою та системний trace залишаються необхідними перед production-релізом.

Сирі файли збережено поруч. GUI Android Studio Profiler не автоматизувався, тому вимірювання є реальними системними Android-метриками, але не heap-dump/leak trace.
